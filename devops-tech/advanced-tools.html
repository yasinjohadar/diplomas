🔄 ArgoCD — GitOps

Continuous Delivery لـ Kubernetes

ArgoCD يتأكد أن حالة الكلاستر تطابق ما في Git. إذا غيّر أحد شيئاً يدوياً، يعيده تلقائياً للحالة المطلوبة.

Terminal — ArgoCD App
# تثبيت ArgoCD kubectl create namespace argocd kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml # إنشاء تطبيق argocd app create myapp \ --repo https://github.com/user/repo.git \ --path k8s/overlays/prod \ --dest-server https://kubernetes.default.svc \ --dest-namespace default # مزامنة argocd app sync myapp

🐳 Portainer — إدارة Docker

واجهة رسومية لـ Docker

Portainer يسهل إدارة الحاويات، الصور، الشبكات، و Volumes عبر واجهة ويب بدلاً من سطر الأوامر.

Terminal — Install Portainer
# تثبيت Portainer CE docker volume create portainer_data docker run -d -p 8000:8000 -p 9443:9443 \ --name portainer --restart always \ -v /var/run/docker.sock:/var/run/docker.sock \ -v portainer_data:/data \ portainer/portainer-ce:latest
