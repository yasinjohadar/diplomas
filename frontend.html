القسم الأول (المجاني) - HTML5

دراسة لغة بناء وهيكلة صفحات الويب بالكامل

مقدمة للغة HTML وأساسيات البناء والوسوم
العناوين الرئيسية، الفرعية، والفقرات النصية
إدراج الروابط التشعبية والصور الديناميكية
القوائم المنظمة والغير منظمة (Lists)
النماذج (Forms) وحقول الإدخال المتعددة
بناء وتخصيص الجداول (Tables) لعرض البيانات
التنسيق التأسيسي والأنماط الأولية
دمج ملفات الصوت والفيديو وتشغيلها في المتصفح
الجداول المتقدمة والنماذج المعقدة
الوسوم الشائعة والأدوات المساعدة لتهيئة الموقع
تضمين الخرائط الجغرافية (Google Maps)
تجهيز الموقع للتجاوب (Responsive Concepts) وتصميم الواجهات
الأمان السيبراني للواجهات وأفضل الممارسات (Best Practices)
02

القسم الأول (المجاني) - CSS3

تجميل وتنسيق المواقع الإلكترونية باحترافية وبناء مشروع متكامل

مقدمة (Introduction) عن أساسيات التصميم بالمحددات
القواعد الكتابية (Syntax) والتعليقات (Comments)
أنظمة وملفات الألوان المتعددة (Colors: Hex, RGB, HSL)
تخصيص حواف وحدود العناصر (Borders)
الهوامش الخارجية والداخلية (Margin & Padding)
التحكم التفصيلي في الأبعاد (Width & Height)
استيراد وتخصيص الخطوط وأحجامها (Fonts)
استخدام مكتبات الأيقونات العالمية (Icons)
تنسيق وتجميل الروابط التفاعلية (Links)
جدولة الواجهات الاستعراضية (Tables Styling)
طرق عرض العناصر الانسيابية (Display: Block, Inline, Matrix)
مواقع وتمحور العناصر على الشاشة (Positions)
ترتيب المحاور وشفافية الطبقات (Z-index & Opacity)
المحاذاة الجانبية والمركزية (Alignment)
العناصر التكميلية الوهمية (Pseudo Elements & Classes)
فلاتر وتأثيرات الصور (Photos Filters)
وحدات القياس المتجاوبة والمرنة (Units: px, em, rem, vh)
محددات العناصر الشجرية (Advanced Selectors)
تأثيرات النصوص والظلال (Text Shadow & Transitions)
تصميم وتنفيذ الخلفيات المتعددة (Backgrounds & Gradients)
تنسيق وتجميل القوائم التصفحية (Lists styling)
هندسة توزيع العناصر الحديثة باستخدام (Flexbox)
بناء التخطيط الشبكي ثنائي الأبعاد (Grid Layout)
المشروع الختامي: بناء مشروع متكامل لشركة لتوظيف كل ما سبق
03

القسم الثاني - المعسكر

أطر العمل، المشاريع الاحترافية، التحكم بالإصدارات وإدارة الاستضافة المتقدمة

دراسة إطار العمل (Bootstrap) بالكامل لهيكلة مرنة
بناء مشروع متجر الكتروني متكامل باستخدام HTML + CSS + Bootstrap
بناء مشروع لوحة تحكم (Dashboard) متكاملة باستخدام Bootstrap
تنفيذ تحدي شامل ومتقدم لبناء موقع لإدارة الوجبات داخل المطاعم
دراسة وتطبيق إطار العمل الوظيفي (Tailwind CSS) بالكامل
بناء مشروع منصة تعليمية (LMS - موقع إدارة وبيع الكورسات)
تنفيذ تحدي شامل لبناء متجر رقمي كامل باستخدام Tailwind CSS
دراسة وتطبيق معالج الـ CSS المتقدم (SASS) بالكامل
بناء مشروع مخصص لموقع التسويق العقاري باستخدام الـ SASS
تنفيذ تحدي شامل لبناء منصة وساطة للبحث عن الوظائف
احتراف مجموعة من أهم المكتبات الديناميكية (Libraries) اللازمة لسوق العمل
شرح وأساسيات (Git and Github) وإدارة المشاريع برمجياً وعزل الإصدارات
شرح التحكم بالسيرفرات (CPanel)، النطاقات، ورفع المواقع بأحدث الطرق
ميزة: يحصل كل طالب على حساب (كانفا برو) مجاناً لمدة عام كامل
ميزة: يحصل كل طالب على مكتبة قوالب (مدفوعة) ضخمة لمشاريع متعددة
