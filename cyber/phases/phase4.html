Blue Team Fundamentals

قبل أن تهاجم، يجب أن تعرف كيف تدافع. هذه المرحلة تعلمك كيف تؤمن الأنظمة، تكتشف التسلل، وتحلل السجلات لاكتشاف الأنشطة المشبوهة.

🔒

System Hardening

تأمين Linux وWindows — تعطيل الخدمات غير الضرورية، إعداد جدران الحماية.

📊

SIEM

مركز عمليات الأمن — جمع وتحليل السجلات من مصادر متعددة.

🚨

IDS/IPS

أنظمة كشف ومنع التسلل — Snort وSuricata.

🏢

Active Directory

إدارة الهويات والصلاحيات في بيئات المؤسسات.

Terminal — Hardening Commands
# تعطيل root login sudo passwd -l root # إعداد جدار الحماية ufw default deny incoming ufw allow 22/tcp ufw allow 80/tcp ufw allow 443/tcp ufw enable # فحص الملفات المعدلة find / -perm -4000 -type f 2>/dev/null # عرض المستخدمين المسجلين who last -a # تثبيت التحديثات الأمنية تلقائياً apt install unattended-upgrades -y

Splunk — Search Queries
# بحث عن محاولات فاشلة index=main "Failed password" | stats count by src_ip # عرض أكثر IPs محاولة index=main "Failed password" | top limit=10 src_ip # تنبيه عند أكثر من 10 محاولات index=main "Failed password" | stats count by src_ip | where count > 10
