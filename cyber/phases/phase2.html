💻 أوامر Nmap

Terminal — Nmap Scanning
# مسح سريع nmap 192.168.1.0/24 # مسح تفصيلي مع اكتشاف الخدمات nmap -sV -sC -O 192.168.1.100 # مسح كل المنافذ nmap -p- 192.168.1.100 # مسح سريع مع اكتشاف OS nmap -A -T4 target.com # حفظ النتائج nmap -oN scan.txt 192.168.1.100

🔐 التشفير العملي

Terminal — OpenSSL Commands
# إنشاء شهادة ذاتية التوقيع openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes # تشفير ملف openssl enc -aes-256-cbc -salt -in secret.txt -out secret.enc # فك التشفير openssl enc -d -aes-256-cbc -in secret.enc -out decrypted.txt # فحص شهادة موقع openssl s_client -connect example.com:443 -servername example.com
