💻 أوامر أساسية

Terminal — Linux Basics
# التنقل بين المجلدات cd /home/user/Documents pwd # عرض المسار الحالي ls -la # عرض كل الملفات بالتفاصيل # إدارة الملفات mkdir -p project/src cp file.txt backup/ mv old.txt new.txt rm -rf temp/ # البحث grep -r "password" /etc/ find / -name "*.conf" 2>/dev/null # الصلاحيات chmod 755 script.sh chown user:group file.txt

🔑 SSH — الاتصال الآمن

Terminal — SSH Commands
# إنشاء زوج مفاتيح ssh-keygen -t ed25519 -C "cyber@diploma" # نسخ المفتاح للسيرفر ssh-copy-id user@192.168.1.100 # الاتصال ssh user@192.168.1.100 # نقل ملفات scp file.txt user@192.168.1.100:/home/user/
⚠️ عطّل الدخول بكلمة مرور في SSH واستخدم المفاتيح فقط: PasswordAuthentication no في /etc/ssh/sshd_config
